PC ⇄ GitHub データ引越しツール

「自分のPCでは見えるのにGitHubで見えない」ときの解決手順:
① 自分のPCで下の「📋 データをコピー」をクリック。
② GitHub Pagesを開き、この画面を出して貼り付け、「📥 このデータを取り込む」をクリック！
これで手元のデータが完全にGitHub側に引き継がれます。

Googleスプレッドシート(GAS)連携設定

GitHub Pagesで本システムを動かす場合、ここにGoogle Apps Scriptの「ウェブアプリURL」を設定することで、スプレッドシートとリアルタイム同期されます。
